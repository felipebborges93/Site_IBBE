## Visual Hierarchy & Anchors

- **Página `/privacidade` (Linguagem Clara):**
  1. *Cabeçalho do Documento:* Título editorial `Política de Privacidade & Proteção de Dados`, subtítulo com data de última atualização em linguagem acolhedora.
  2. *Cards Informativos em Linguagem Simples:* Blocos claros com ícones Phosphor explicando:
     - Pedidos de Oração (nenhum cadastro obrigatório, opção anônima real).
     - Proteção contra Spam (hashing unidirecional de IP, sem retenção persistente de dados de rastreamento).
     - Ausência de Cookies de Rastreamento (apenas telemetria técnica de performance sem identificação pessoal).
  3. *Canal de Contato do Encarregado (DPO):* Seção clara no rodapé com e-mail direto para dúvidas sobre privacidade.

- **Aviso de Privacidade no Formulário de Oração:**
  - Pequeno texto discreto abaixo do botão de envio (`text-xs text-marinho/70`): *"Ao enviar, você concorda com nossa [Política de Privacidade](/privacidade). Pedidos podem ser feitos anonimamente."*

- **Acessibilidade Universal:**
  - Skip link invisível por padrão e visível no topo ao pressionar `Tab`: *"Saltar para o conteúdo principal"*.
  - Anéis de foco claros e de alto contraste em todos os controles interativos.
  - Respeito automático à preferência do sistema `prefers-reduced-motion: reduce` desativando animações supérfluas.

## UI Considerations

Applicable state considerations resolved: 4 covered, 1 backstop, 0 unresolved

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | Política de Privacidade | ✅ covered | A página estática é autocontida e não depende de chamadas de API assíncronas para renderização. |
| error | Links e navegação | ✅ covered | Todos os links internos usam Next.js Link com prefetch e fallback nativo caso JavaScript esteja desativado. |
| loading | Carregamento de fontes e imagens | ✅ covered | Fontes utilizam `display: swap` prevenindo FOIT; imagens têm placeholders dimensionados com `priority` onde cabível. |
| focus | Navegação por teclado em toda a UI | ✅ covered | Foco universal via `:focus-visible` com anel contrastante de 2px e deslocamento de 2px (`offset`). |
| long-text | Textos explicativos na página `/privacidade` | 🧪 backstop | Estrutura delimitada por `max-w-3xl` centralizada, garantindo linha tipográfica ideal de 60-75 caracteres por linha. |
