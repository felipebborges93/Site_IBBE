## 3. Integração Cross-Phase e Fluxos E2E

1. **Fluxo de Navegação e Conteúdo:**
   - Landing page com âncoras para todas as seções (`#historia`, `#cultos`, `#eventos`, `#grupos`, `#ministerios`, `#visita`, `#localizacao`, `#pix`).
   - Rota `/nossa-historia` ligada por link a partir da home.
   - Cálculo automático do Próximo Culto baseado em `content/services.ts`, com badge pulsante e link direto para o culto.

2. **Fluxo de Oração e Moderação:**
   - Formulário em `/oracao` com validação Zod client+server, contador de caracteres, modo anônimo e honeypot anti-spam.
   - Rota administrativa `/admin/oracao` protegida por Middleware com redirecionamento de usuários não autenticados.
   - APIs REST do telão (`/api/prayer-requests/display`) autenticadas por `TELAO_API_TOKEN`.

3. **Fluxo de Transmissões (YouTube):**
   - Suporte a YouTube Data API v3 com cache ISR de 30 minutos e fallback triplo em cascata (API → RSS Feed → Card amigável com link do canal).
