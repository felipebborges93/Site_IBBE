<objective>
Implementar a infraestrutura completa de Pedidos de Oração (Phase 5), desde o banco de dados (Supabase), formulário público com segurança anti-spam, painel de moderação administrativa e endpoints dedicados ao telão da igreja.
</objective>

<context>
Conforme definido em 05-CONTEXT.md, a arquitetura usará:
- Server Actions + React Hook Form + Zod para manipulação do formulário.
- Supabase para armazenamento (`prayer_requests`) com RLS restrito (anon = insert only).
- Middleware do Next.js para proteger as rotas de administração (`/admin/*`).
- Honeypot e IP Hash para mitigação de spam e rate limit.
- Um token estático em `.env` para autenticar a API do Telão.
</context>
