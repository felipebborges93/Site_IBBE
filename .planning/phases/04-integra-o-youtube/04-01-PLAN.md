# Plan: Integração YouTube (Tracer)

**Requirements:** LIVE-01, LIVE-02

## 1. YouTube Service Foundation
- Create `lib/youtube.ts`
- Implement `getLatestLives` function using YouTube Data API v3 to fetch `playlistItems` and `videos` details.
- Ensure the fetch request uses Next.js ISR with a 30-minute revalidation interval (`next: { revalidate: 1800 }`).

## 2. UI Component for Latest Lives
- Create `components/youtube/YouTubeSection.tsx` (or update existing) as a Server Component.
- Import `getLatestLives`.
- Render a grid of `Card` components for the 4 most recent videos.
- Use native Google URL for thumbnails: `i.ytimg.com/vi/[ID]/maxresdefault.jpg`.

## 3. Home Page Integration
- Integrate the `<YouTubeSection />` into `app/page.tsx` near Events or Ministries.

## 4. Verify Execution
```bash
npx tsc --noEmit
npm run build
```
