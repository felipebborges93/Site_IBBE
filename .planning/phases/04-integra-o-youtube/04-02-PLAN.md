# Plan: Integração YouTube (Fallbacks & Indicador Ao Vivo)

**Requirements:** LIVE-03, LIVE-04

## 1. Fallbacks para Falha de API
- Update `lib/youtube.ts` to implement a fallback to RSS feed using native `fetch` when the YouTube Data API v3 fails or quota is exceeded.
- Process the RSS feed using light string/regex parsing.
- Provide a final fallback to a friendly "Ver no YouTube" object if both API and RSS fail.

## 2. Friendly "Ver no YouTube" Card
- Create or update the `Card` fallback UI to use the site's Design System (`components/ui/Button.tsx`).
- Ensure the site does not break when both API and RSS fail.

## 3. Indicador "AO VIVO"

- Update `app/page.tsx` or the Hero component to make the "Assistir ao vivo" CTA link dynamically point to the live video URL if one is currently in progress. 
- The CTA must open the live directly in a new tab (`target="_blank"`).
